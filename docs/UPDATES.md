# Обновление приложения

Windows и Linux 2.1.1 проверяют доступность новой версии через HTTPS
Когда версия доступна, используйте действие обновления в приложении
Перед заменой файлов проверяются цифровая подпись каталога, платформа, размер и SHA-256 каждого файла
Приложение завершает соединение, заменяет рабочие файлы и перезапускается; при активном соединении запрашивается его восстановление

## Windows

Обновляется текущая установленная копия приложения
Для защищённого каталога, например Program Files, может потребоваться подтверждение Windows
Подписки и настройки хранятся отдельно от установочных файлов и сохраняются

## Linux

DEB, RPM, Arch-пакет и ZIP используют один комплект Qt и общий канал обновлений
При первом запуске из пакета или ZIP приложение создаёт пользовательский рабочий каталог `~/.local/opt/horizon-connect/bin`
Именно он обновляется из приложения, независимо от пакетного менеджера дистрибутива

Пакет в `/opt/horizon-connect` остаётся исходным комплектом для первого запуска
Установка нового системного пакета не перезаписывает уже обновлённый пользовательский комплект
Поэтому версия в пакетном менеджере и версия запущенного приложения после встроенного обновления могут различаться

Пользовательские настройки и подписки находятся вне обновляемого комплекта
Удаление системного пакета не удаляет пользовательский комплект и данные
Системный TUN использует отдельный привилегированный компонент; при обновлении ядра может потребоваться подтверждение polkit

Для прежних пользовательских установок Arch с системным Qt 6.12 сохранён отдельный совместимый канал
Переносимый комплект требует glibc 2.35 или новее и остальных зависимостей, указанных в инструкции установки

## Если обновление не устанавливается

Проверьте доступ к интернету, свободное место, дату и время системы
Сообщение об ошибке подписи или проверке файла означает, что установка была отклонена
Повторите проверку позже или скачайте установщик из [релизов](https://github.com/WireonWN/H-Connect/releases)

При обращении укажите платформу, версию и текст ошибки без паролей, ключей и ссылок подписок

## Автозапуск

В настройках приложения откройте раздел запуска и окна
Автозапуск приложения и автоматическое подключение включаются отдельно
Ниже можно выбрать страну для подключения после запуска
Выбор применяется к доступным серверам ваших подписок
