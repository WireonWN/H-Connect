# Обновления Horizon Connect

## Android 2.3.0

Обновлён мобильный интерфейс и расширены возможности подключения

- Переработаны стеклянные панели, уведомления и переходы между экранами
- Добавлены свайпы между вкладками и закрытие уведомлений движением вверх
- Темы, иконки, шрифты и размеры элементов собраны в одном разделе
- Настройки стали компактнее и понятнее
- Добавлена поддержка WireGuard, AmneziaWG, OpenVPN, IKEv2 и SSH Tunnel
- Доработаны импорт конфигураций и обработка параметров серверов
- Исправлена обработка Salamander в Hysteria2 и работа SSH Mux с параллельными соединениями
- Исправлены ошибки интерфейса и подключения

Собственное ядро получило название **AirX**
Оно написано на Rust и отвечает за подключения, передачу трафика и работу протоколов

Новые протоколы продолжают тестироваться: доступность протокола в списке не означает, что все его режимы одинаково проверены

Android 8.0+, код версии 64

## Windows 2.1.1

Обновление настольного интерфейса, автозапуска и установки

- Обновлены стеклянные панели, уведомления и плавные переходы
- Настройки внешнего вида собраны вместе: темы, иконки, шрифты и размеры элементов
- Упрощена структура настроек, добавлены сведения о версии и сборке в разделе «О приложении»
- Исправлен запуск при входе в Windows и согласована настройка автозапуска с установщиком
- Добавлен выбор страны для автоматического подключения после запуска
- Доработаны импорт конфигураций и обработка параметров серверов
- Исправлены обработка Salamander в Hysteria2 и параллельные соединения SSH Mux
- Настроены подписанные обновления из приложения с сохранением настроек и подписок
- Добавлены аналитика использования и минимальные отчёты о сбоях
- В установщик включены необходимые библиотеки среды выполнения

Windows 10/11 x64, установщик `.exe`

## Linux 2.1.1

Добавлено и оптимизировано собственное ядро **AirX 0.3.0** для Linux
Ядро написано на Rust и отвечает за подключения, передачу трафика и работу протоколов

- Доработаны импорт серверов, обработка конфигураций и стабильность подключений
- Исправлены обработка Salamander в Hysteria2 и работа SSH Mux с несколькими соединениями
- Обновлены панели и уведомления, упорядочены настройки внешнего вида
- Исправлен автозапуск в пользовательской сессии Linux
- Добавлен выбор страны для подключения после запуска
- В разделе «О приложении» доступны версии клиента и ядра, сведения о сборке и компонентах
- Добавлены аналитика и минимальные отчёты о сбоях
- Подготовлены пакеты для разных дистрибутивов и переносимый комплект с Qt внутри
- Все форматы используют обновление из приложения с проверкой подписи и сохранением пользовательских данных

Linux x86_64 (.deb: Debian / Ubuntu; .rpm: Fedora; .pkg.tar.zst: Arch / Manjaro; .zip: другие совместимые дистрибутивы)
Требуются glibc 2.35+, Python 3, OpenSSL 3 и системные зависимости из инструкции установки
Установка, запуск и замена подписанного комплекта проверены в изолированных Ubuntu 22.04, Debian 12, Fedora 44 и Arch
