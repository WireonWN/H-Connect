# Обновления Horizon Connect

## Android 2.4.0

- Исправлены подключения в LTE и к серверам WhiteList
- Результаты параллельных проверок обновляются в списке серверов по мере завершения
- Обновлён выбор сервера при переходе между Wi-Fi и мобильной сетью

Android 8.0+, пакет `com.horizon.connect`, код версии `66`
APK содержит библиотеки для `arm64-v8a`, `armeabi-v7a`, `x86` и `x86_64`
Сертификат подписи совпадает с APK 2.3.0, код версии предыдущего выпуска - `64`

## Windows 2.2.0

- В системном туннеле VLESS Vision один UDP-сокет сохраняет внешний порт при смене адресата после запроса STUN, что важно при установке соединения Parsec
- Лимит одновременных TCP-соединений в туннеле увеличен с 64 до 256, буферы выделяются по мере необходимости
- Исправлена обработка IPv6-адресов в браузере при работе через VPN

Windows 10/11 x64, сборка `2026111801`
Манифест автообновления подписан, установщик EXE поставляется без подписи Authenticode

## Linux 2.2.0

- DEB для Debian и Ubuntu, RPM для Fedora, PKG.TAR.ZST для Arch и Manjaro, ZIP с комплектом Qt для переносимой установки
- Встроенное обновление проверяет подпись каталога и SHA-256 файлов, сохраняя подписки и настройки в пользовательском профиле

Linux x86_64, glibc 2.35+, Qt 6.8, сборка `2026111702`
