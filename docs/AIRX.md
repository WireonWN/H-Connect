# Ядро AirX

AirX является сетевым ядром Horizon Connect
Оно отвечает за подключение к серверам, передачу трафика и управление состоянием соединения

Основная логика написана на Rust
Клиент отвечает за интерфейс, серверы, подписки и пользовательские настройки
AirX выполняет сетевые задачи и передаёт клиенту состояние подключения

## Возможности

- Подключение к серверам с использованием разных протоколов
- Передача трафика в режиме VPN или локального прокси
- Обработка TCP- и UDP-трафика в поддерживаемых режимах
- Применение настроек DNS и маршрутизации
- Управление подключением, остановкой и восстановлением сессии
- Передача состояния соединения и диагностических сообщений клиенту

## Протоколы

| Протокол | Назначение |
| :--- | :--- |
| VLESS | Прокси-подключение с различными вариантами транспорта и защиты |
| VMess | Прокси-подключение с аутентификацией и защитой передаваемых данных |
| Trojan | Прокси-подключение с использованием TLS |
| Shadowsocks 2022 | Шифрованное прокси-подключение |
| Hysteria2 | Прокси-подключение для передачи TCP- и UDP-трафика |
| TUIC v5 | Прокси-подключение на основе QUIC |
| NaiveProxy | Подключение через HTTPS-прокси |
| WireGuard | VPN-туннель для передачи IP-трафика |
| AmneziaWG | VPN-туннель семейства WireGuard с обфускацией трафика |
| OpenVPN | VPN-подключение по TCP или UDP |
| IKEv2/IPsec | VPN-подключение с использованием IPsec |
| SSH Tunnel | Туннелирование соединений через SSH |

Набор доступных протоколов, транспортов и параметров определяется конкретной сборкой
Поддержка протокола не означает поддержку всех его расширений и вариантов конфигурации

## Режимы работы

**VPN**

Horizon Connect использует системные возможности платформы для направления трафика через подключение
Область действия VPN определяется настройками приложения и операционной системы

**Локальный прокси**

Приложения могут направлять соединения через локальный SOCKS5-прокси
Для этого в них должна быть предусмотрена настройка прокси

Доступность режимов зависит от платформы и сборки

## DNS и маршрутизация

AirX участвует в обработке DNS-запросов и применении правил направления трафика
Настройки позволяют управлять разрешением имён и выбором пути подключения в поддерживаемых режимах

Совместимость отдельных правил и способов разрешения имён зависит от выбранного протокола
Набор настроек может различаться между платформами

## Состояние подключения

Ядро сообщает клиенту о ходе подключения, работе соединения и возникающих ошибках
Эти сведения используются для отображения статуса и диагностики

Доступность сервера и работоспособность подключения оцениваются отдельно
Обычный пинг сам по себе не подтверждает прохождение пользовательского трафика

## Совместимость

Сетевые возможности и требования к разрешениям определяются операционной системой
Состав функций может отличаться между Android, Windows и Linux

Используемое ядро и доступные режимы зависят от конкретного выпуска Horizon Connect
Сведения об опубликованных сборках приведены в [инструкции по установке](../INSTALL.md) и описаниях релизов

## Версии и обновления

Версия AirX ведётся отдельно от версии Horizon Connect
Обновления ядра могут включать исправления соединений, улучшения совместимости и изменения сетевых возможностей

Список изменений, доступных функций и известных ограничений указывается в описании релиза
